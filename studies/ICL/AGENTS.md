# Codex / ChatGPT 작업 지침

이 디렉터리는 지속적으로 발전하는 **ICL 스터디 원본 문서**입니다.

## 작업 범위
- 사용자가 별도로 요청하지 않으면 `studies/ICL/` 바깥 파일을 변경하지 않습니다.
- 요청한 문서만 수정하며, 기존 학습 기록을 임의로 삭제하거나 대체하지 않습니다.
- 문서 제목, 번호 및 상대 링크를 유지합니다.

## 기술적 정확성
- 수학적 주장마다 기호, 가정, 유도 과정을 명시합니다.
- 출처를 구분합니다: [논문], [강의 자막], [추가 설명], [검증 필요].
- 강의 자동 자막의 오인식은 원문 논문과 대조합니다.
- 일반 Softmax Attention과 단순화된 Linear/Dot-Product Attention의 등가성을 무조건 주장하지 않습니다.
- 추론 중 Gradient Descent의 효과를 해석하는 것과 실제 가중치 업데이트를 엄격히 구분합니다.
- 논문이 직접 입증하지 않은 사실을 입증된 결과로 작성하지 않습니다.

## 문서 서식
- Markdown + 표준 LaTeX 수식을 사용합니다.
- 각 장: 학습 목표 → 정의/가정 → 수학적 유도 → 직관 → 한계 → 참고 문헌.
- 새로운 장을 만들면 `README.md`의 목차를 갱신합니다.
- 한글로 작성하고 inference=추론, reasoning=사고를 사용합니다. Expert/Agent는 필요 시 영어를 유지합니다.

## 동기화
- 수정 전에 원격 변경사항을 확인하고, 동일 파일의 동시 변경을 피합니다.
- 의미 있는 수정은 별도 Commit으로 남깁니다.
- 공개 블로그 게시나 원격 배포는 명시적 요청 없이 수행하지 않습니다.
